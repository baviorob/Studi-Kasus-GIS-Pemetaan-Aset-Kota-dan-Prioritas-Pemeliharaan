Studi Kasus GIS: Pemetaan Aset Kota dan Prioritas Pemeliharaan
Notebook praktikum ini disusun berdasarkan tema webinar Career and Competition in Industrial Era with GIS oleh Widi Primadeva. Materi sumber membahas asset/property management, pemetaan infrastruktur, data spasial beratribut, penggunaan Python, teknologi open-source, integrasi data, dan portofolio GitHub.
Isi notebook
- Memuat dan memeriksa CSV
- Merangkum jenis dan kondisi aset
- Membuat peta titik interaktif dengan Folium
- Membuat daftar prioritas pemeliharaan dan ringkasan biaya
- Mengekspor titik menjadi GeoJSON
Menjalankan
Buka studi_kasus_gis_aset_kota.ipynb di Google Colab dan jalankan sel secara berurutan. Saat diminta, unggah dataset_dummy_aset_gis.csv.
Dataset dan batasan
CSV berisi 500 baris data sintetis. Koordinat tidak mewakili lokasi aset sebenarnya; status dan estimasi biaya juga dibuat untuk latihan. Jangan gunakan untuk pengambilan keputusan nyata.
